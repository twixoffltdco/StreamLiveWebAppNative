# StreamLive WebApp 1.4.3 · Liquid Glass (build 143)

## Установка
1. Распакуй ZIP в **корень** сайта (рядом с `includes/`).
2. Должны появиться `/webapp/`, `/assets/webapp/`, `/api/native_*.php`.
3. Проверка: `https://сайт/webapp/verify.php`
4. Приложение: `https://сайт/webapp/?v=143`

## Обновление с build 142
Перезапиши файлы из ZIP. Открой `/webapp/?v=143` в инкогнито или сбрось Service Worker (Настройки → 7 тапов по версии → разработчик → сброс SW).

## Важно

# StreamLive Native

Нативное приложение StreamLive на Веб Браузере для **Android, iOS и Windows** с богатыми плеерами.

![cover](assets/cover.png)

## Что внутри
- Анимированный «вайб»-вход и регистрация (плавающие doodle-иконки, волны, градиент)
- Каталог ТВ/радио каналов, поиск, фильтры
- Нативный плеер (media_kit): HLS `m3u8` и `mp4`
- Живой чат канала (опрос каждые 3 с, отправка с аккаунта)
- Список видео, профиль, выбор зеркала, автопереключение между зеркалами
- Зеркала: `streamlivetv.freedev.app`, `domtv.blyz.ru`, `streamliveru.web1337.net` (файл `lib/config.dart`)

## Важно: сначала серверная часть
Приложению нужны два файла на сервере — см. `server_addon/README.txt`
(`api/native_auth.php` и `api/native_channel.php`). Без них вход и плеер не заработают.

Источники `youtube / vk / rutube / iframe` не дают прямой поток — для них приложение
открывает плеер сайта во внешнем браузере. `mp4` и `m3u8` играют нативно.




## Локальный запуск (если есть Flutter)
```bash
flutter create --platforms=android,ios,windows --project-name streamlive .
flutter pub get
dart run flutter_launcher_icons
flutter run
```
